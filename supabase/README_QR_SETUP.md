## セキュリティ境界
- 招待レコードは公開APIから直接読めず、Edge Functionのサーバー側だけで作成・消費する。
- 管理者の認証・権限はDBで確認。スタッフは対面確認する。
- QRのトークンは十分長い乱数とし、DBにはSHA-256ハッシュだけ保存する。
- 有効期限・使用済み・取り消し状態を原子的に検証する。
- **QRを消費するだけでログイン済みにはしない**。Supabase Authの正式なセッション発行方式を先に検証する。
- 旧端末失効にはRLSと全RPCを含むサーバー側のチェックが必要。単なるログアウトでは即時遮断を保証できない。
